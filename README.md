# Trader / Genjutsu UI clone

A high-fidelity local recreation of the public Higgsfield Genjutsu video workspace at `/ai/video?model=genjutsu`.

## Run

```bash
npm run build
npm run dev
```

The interface includes model selection, source and character-sheet uploads, prompt shortcuts, advanced motion/identity controls, generation state, settings, and responsive layouts. The generation button is intentionally local-only until a real provider API is connected; it never pretends to render a proprietary Higgsfield result.
